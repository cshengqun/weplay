# 球局轮转（weplay）

一个微信小程序：球局报名 + 根据报名名单自动生成 **单打 / 双打 / 混双** 轮转表。

## 功能

- **球局管理**：新建球局（名称、日期、场地数），删除球局。
- **报名管理**：录入球员姓名，可标记性别（男/女，混双必需）与水平（新手/进阶/高手），随时移除或清空名单。
- **轮转生成**：选择类型（单打/双打/混双）、场地数、轮数（自动排完全部组合，或自定义轮数），一键生成。
- **轮转表**：按轮次分场地展示对阵，标注每轮轮空名单；统计每人上场次数，直观看到轮换是否公平。
- **确认流程**：生成轮转后先进入预览，核对对阵后点「确认轮转」锁定；确认后**不能重新生成**，只能录入比分，防止误操作。
- **比分录入**：生成时设置每场目标分数（如 15 / 21 分，可自定义）；确认后每场直接输入双方实际得分（如 21:18），得分高者胜，自动标识胜方。
- **结果多方确认**：组织者录入比分后，上场球友在分享卡片中可「确认比分」或「比分有误」；全部相关方确认后结果生效，异议场次需组织者修改后重新确认，为后续段位排位提供可信数据。单机/手动名单（无 OpenID）自动确认，不增加操作负担。
- **段位全国榜**：采用 ELO 机制（初始 1000，前 5 场定级赛 K=48，定级后 K=24，球王以上 K=16）。单打/双打/混双分项 ELO 独立，综合 ELO 按 0.4/0.3/0.3 加权，映射青羽→白羽→金羽→翡翠→钻石→星耀→最强球王→传奇球王的段位与星级。比赛全部确认后自动结算：碾压局低收益、爆冷高收益，双打按队伍均值结算防止抱大腿刷分；总榜页由胜场榜升级为全国段位榜。
- **确认闭环（超时自动生效 + 订阅消息）**：比赛录入后进入待确认，若 **48 小时**内无人确认且无异议，云函数定时触发器（每小时）自动确认并结算段位，避免因个别球友未确认导致段位永久挂起；有异议的场次不自动生效。报名 / 确认时可授权订阅消息，在「待确认 / 有异议 / 段位更新」时收到提醒（需在小程序后台申请订阅消息模板并填入 `utils/notify.js`）。
- **积分排名**：录入比分后自动生成积分榜。积分规则：**胜 +2 分、负 +1 分**（按个人累计，双打/混双搭档轮换不影响个人积分）；排名按 积分 > 净胜分 > 胜场 > 姓名 排序，同分并列名次相同，前三名高亮。
- **分享与在线报名（云开发）**：创建球局后可分享到微信群，球友点开分享卡片即可查看球局信息并在线报名，组织者端自动合并最新名单。
- **比赛完成态**：任一类型轮转全部记完比分后，球局自动进入"已完成"模式——只保留比赛结果、球局信息与报名名单（只读），不再显示报名表单和生成轮转入口；首页与球局页均展示"🏁 比赛已结束"。
- **结果云端同步**：轮转表与比分随操作同步到云数据库，任何设备点开分享卡片即可查看最终结果（积分榜 + 每轮对阵比分），无需安装小程序数据。
- **数据本地存储**：球局数据保存在手机本地（wx.storage）；开通云开发后额外同步到云端供他人报名与查看结果。

## 快速开始

1. 打开 **微信开发者工具**（https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html）。
2. 「导入项目」→ 选择本目录 `weplay`。
3. AppID 选 **测试号**（本工程已配置游客模式 `touristappid`，可直接体验）。
4. 编译预览即可使用。

> 提示：多人共享报名需要云开发/后端，当前版本为单机本地版，适合组织者一人登记后投屏或分享截图使用。

## 发布到线上（微信小程序）

发布需要「微信公众平台小程序账号 + 微信开发者工具 + 审核」，账号与扫码环节必须本人操作，流程如下：

1. **注册小程序账号（必须本人）**
   打开 https://mp.weixin.qq.com → 立即注册 → 选择「小程序」→ 用未绑定过公众号/小程序的邮箱注册。
   个人主体即可（免费），注册后到「设置 → 账号信息」复制 **AppID** 和 **AppSecret**。

2. **填入真实 AppID**
   把 `project.config.json` 里的 `"appid": "touristappid"` 改成你的真实 AppID（可让 AI 代改）。

3. **安装并登录微信开发者工具（扫码必须本人）**
   下载 macOS 版：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
   打开工具 → 手机微信扫码登录 → 「导入项目」选择本目录 `weplay`，AppID 选「小程序」并填入你的 AppID。

4. **上传代码**
   工具右上角「上传」按钮（或命令行 `cli upload --project <路径> --version 1.0.1 --desc "新增比分录入与积分排名"`），
   版本号建议按 `1.0.0` 递增。

5. **提交审核并发布（必须本人）**
   登录 mp.weixin.qq.com → 「管理 → 版本管理 → 开发版本」→ 提交审核。
   审核前建议在「设置 → 服务类目」选择合适类目（如「工具」类），若开启收集用户信息需配置「用户隐私保护指引」。
   审核通过后回到「版本管理」点「发布」。

> 审核通常 1~7 天；期间可先用「体验版」把二维码发给朋友实测，确认无误再提审。

## 开通云端分享（分享到微信群 + 在线报名）

分享报名依赖微信**云开发**（免服务器，有免费额度）。开通步骤：

1. **开通云开发**：微信开发者工具 → 顶部工具栏点「云开发」→ 开通并创建环境（建议环境名如 `weplay`，免费额度即可）。
2. **创建数据库集合**：云开发控制台 → 数据库 → 新建两个集合，名称必须是 `activities` 和 `rank`。
3. **部署 activity 云函数**：开发者工具左侧目录树找到 `cloudfunctions/activity`，右键 → 「上传并部署：云端安装依赖」，等待提示完成（约 1 分钟）。该云函数含定时触发器（`config.json`，每小时第 5 分钟），部署时工具会提示「是否创建定时触发器」，选择确认即可；触发器负责把超时（48h）未确认且无异议的比赛自动确认并结算。
4. **设置集合权限**：
   - `activities`：权限设置 → 选「所有用户可读，仅创建者可读写」。报名、比分、确认、删除等写操作都经 activity 云函数在服务端鉴权，客户端无法直接改数据。
   - `rank`：权限设置 → 「自定义安全规则」，填 `{"read": true, "write": false}`。段位榜所有人可读，段位仅云函数可写，客户端无法改分。
5. **首次历史回溯**：进入「总榜」页 → 底部点「重建（历史回溯）」，把历史已确认比赛一次性换算成段位（之后新比赛在全部确认后自动结算，无需再手动）。
6. **配置环境 ID（可选）**：若只创建了一个云环境，留空即可（自动使用默认环境）；若有多个环境，把环境 ID 填到 `utils/cloud.js` 顶部 `CLOUD_ENV`。

开通后使用方式：

- 组织者在「球局信息」页给球局起名 → 点「分享到微信群」→ 把分享卡片发到群里。
- 球友点开卡片 → 若球局未完成：查看信息并在线报名；若已完成：直接查看比赛结果（积分榜 + 每轮比分）。
- 组织者回到球局页会自动合并云端名单（也可点「刷新云端」手动拉取）；删除球局会同时删除云端记录。
- 轮转表、比分在生成/录入时自动同步云端；任何设备打开分享卡片都能看到结果。

> 说明：当前为"所有用户可读写"的简化权限，组织者与球友同时操作时以最后一次写入为准；数据量小、球友群场景下完全够用。

## 订阅消息（可选）

在「待确认 / 有异议 / 段位更新」时提醒用户，需先申请模板（本人）：

1. 登录 mp.weixin.qq.com → 功能 → 订阅消息 → 公共模板库，选用对应模板，取得模板 ID。
2. 把模板 ID 填入 `utils/notify.js` 顶部 `TMPL`（`pendingConfirm` / `dispute` / `settled`）。
3. 云函数 `sendSub` 的 `data` 字段需按所选模板的实际字段（thing / phrase / number / time…）补全。
4. 重新部署 activity 云函数。

未配置模板 ID 时，订阅授权与发送都会安全跳过，不影响其他功能。

## 轮转算法说明

采用**圆桌轮转法（Circle Method）**，保证：

- **单打**：任意两名球员恰好对阵一次；奇数人数时每人恰好轮空一次。
- **双打**：任意两名球员恰好搭档一次；每轮 4 人一场、两两成组对阵。
- **混双**：任意一男一女恰好搭档一次（男女错位轮转）。
- **公平性**：场地不足时，每轮通过全局前瞻贪心选择"轮休组合"，让每人的上场次数尽量均衡（一般相差不超过 1~2 场）。
- 场地数小于可排满数时自动降低使用场地；人数不足（单打<2、双打<4、混双<2男2女）会给出明确提示。
- 生成时会随机洗牌球员顺序，多次生成可得到不同对阵。

## 战绩规则（可自行调整）

当前计分逻辑在 `utils/score.js`，默认：

- 生成轮转时设置**每场目标分数**（默认 21，可选 11/15/21 或自定义）；每场双方各录实际得分（如 21:18），**得分高者胜**（0:0 视为未记录，不计入）。
- 生成后需点「确认轮转」锁定，确认后不能再重新生成。
- **战绩榜**统计每人 场次 / 胜场 / 负场 / 胜率 / 净胜分（双打/混双按个人累计，与搭档无关）。
- 排名依次比较：**胜场 → 胜率 → 净胜分（得分 − 失分）→ 姓名**；三项相同则并列名次（如 1、1、3）。
- 比分存储于轮转数据的 `scores` 字段，键为「轮次-场地」，如 `"1-1": { sA: 21, sB: 18 }`。

## 总榜（跨球局）

- 首页顶部「总榜」入口；汇总本机**所有球局**已录比分的战绩，聚合出总胜场与总胜率。
- 通过分享卡片打开的球局（云端）也会在打开时并入本机统计。
- 排名规则与单局战绩榜一致：胜场 → 胜率 → 净胜分 → 姓名。
- **按 OpenID 聚合**：在线报名（带微信 OpenID）的球员按 OpenID 合并——改名也累计同一个人，同名不同人不会混淆；组织者手动添加（无 OpenID）的球员按名字聚合。

## OpenID 身份绑定（无需云函数）

- 云端新建集合 **`me`**，权限选「自定义安全规则」填：
  `{"read": "auth.openid == doc._openid", "write": "auth.openid == doc._openid"}`
- 用户在线报名成功后，昵称/头像/性别/水平写入 `me` 集合（`_openid` 由服务端自动注入，无法伪造）。
- 之后任何设备打开报名页，都会从 `me` 自动带出本人档案——**换手机也不用重新填**。
- 报名记录与轮转快照带 `openid` 字段；未开通 `me` 集合时自动降级为本地记忆。

## 已知限制

- 本地存储 + 云端存储：未开通云开发时，球局数据不跨设备同步、不支持他人在线报名。
- 未设置性别的球员不会进入混双轮转（生成时自动排除并提示）。
- 人数较多且场地较少时（如 10 人 1 片场地双打），部分搭档组合受场地限制无法全部排完，属正常现象；建议此时使用"自定义轮数"。
- 写操作经 activity 云函数在服务端鉴权完成；云函数未部署时，在线报名、比分确认等云端写操作不可用（本地功能不受影响）。组织者与球友同时操作时以服务端最后一次写入为准。
- 段位仅在云端、且比赛全部确认后结算；单机/未部署云函数时不产生段位。段位 ELO 区间为初始建议值，上线后需按真实分布校准；本期暂未实现赛季软重置、地区榜与保护分（拼搏分）抵扣，将在后续迭代补齐。
- 订阅消息需在小程序后台申请模板并填入 `utils/notify.js` 后才会真正发送；未配置模板时该功能静默跳过。超时自动确认依赖云函数定时触发器，需部署含 `config.json` 的云函数后生效。
